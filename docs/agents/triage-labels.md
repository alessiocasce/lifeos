# Triage labels

The five canonical triage roles use their default label strings in `alessiocasce/lifeos`.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

Use this mapping whenever an engineering skill names a triage role. Preserve existing unrelated labels and the existing `wontfix` label. Edit this file if the repository later adopts different label names.
