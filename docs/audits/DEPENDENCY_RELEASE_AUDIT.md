## Retained risks

- vite-plugin-pwa 1.3.0 -> workbox-build 7.4.1 -> @rollup/plugin-node-resolve 16.0.3 -> deepmerge 4.3.1: low prototype poisoning on malicious build configuration/package objects. Registry latest deepmerge remains 4.3.1; no current patched compatible release was available. Treat all build inputs as code; do not build untrusted third-party PRs with secrets.
- vite-plugin-pwa -> workbox-build -> glob 11.1.0 -> minimatch 10.2.6: moderate cancellation/CPU amplification when traversing hostile trees/glob patterns. This repo uses fixed globPatterns; workout/user input never supplies them. Current patched registry alternatives glob 14.0.4 and minimatch 11.0.5 cross upstream major constraints. No speculative overrides were applied.
- The plugin, Workbox and resolver findings are inherited chains, not six independent exploitable runtime services. npm proposes a PWA downgrade to 1.1.0 with force; rejected because this would alter the approved service-worker pipeline and abandon the declared version range.
- Builds remain resource-limited in CI (15-minute job timeout), credential-free, and restricted to reviewed source. This does not remove denial-of-service risk from malicious build inputs. Owner risk acceptance/upstream patch follow-up is required before release.
