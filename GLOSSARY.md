# LifeOS

LifeOS connects personal planning, health, Training, and reflection. These terms describe the Training rest-timer workflow.

## Language

**Rest timer**:
A countdown for the rest period between logged workout sets, associated with a workout session. It can run without background notifications.

**Rest preferences**:
A user's choices for automatic rest timers, default rest duration, and background notifications. They apply across that user's workout sessions.

**Notification preference**:
The user's saved choice to receive background rest notifications. This choice is separate from whether a particular device is registered or currently ready to receive them.

**Device registration**:
The association that allows a particular browser or installed LifeOS app to receive notifications for a user. Registration alone does not establish notification consent or prove delivery.

**Reconnect notifications**:
An explicit user action to renew the current device's notification registration. Reconnecting does not prove that the device displayed a notification.
